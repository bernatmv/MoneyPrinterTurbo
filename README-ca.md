# MoneyPrinterTurbo 💸

### Un generador de vídeos curts amb IA tot en un

Proporciona un <b>tema</b> o una <b>paraula clau</b> per al vídeo, i MoneyPrinterTurbo en generarà el guió, hi trobarà el material visual adequat, crearà els subtítols i la música de fons, i produirà un vídeo curt en alta definició.

## Requisits del sistema 📦

- Plataformes recomanades: Windows 10+, macOS 11+ o una distribució Linux habitual
- El desplegament local requereix Python 3.11 o posterior; es recomana Python 3.11
- No cal una GPU, però se'n recomana una si voleu una transcripció local més ràpida, un processament de vídeo més ràpid o una generació per lots més fluida

| Element | Mínim        | Recomanat      | Òptim       |
| ------- | ------------ | -------------- | ----------- |
| CPU     | 4 nuclis     | 6 a 8 nuclis   | 8+ nuclis   |
| RAM     | 4 GB         | 8 GB           | 16+ GB      |
| GPU     | No necessària | 4+ GB de VRAM | 8+ GB de VRAM |

- Si us baseu principalment en LLM al núvol, TTS al núvol i fonts de material en línia, la CPU i la RAM són més importants que la GPU
- Si feu servir `faster-whisper`, la generació per lots o un processament local més exigent, una GPU millorarà notablement el rendiment

## Instal·lació i desplegament 📥

### Requisits previs

- El desplegament local requereix Python 3.11 o posterior
- A Windows, eviteu rutes del projecte que continguin caràcters no ASCII, caràcters especials o espais

#### ① Cloneu el projecte

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
```

#### ② Completeu la configuració inicial

En el primer inici, el projecte crea `config.toml` a partir de `config.example.toml`, de manera que no cal crear el fitxer manualment. Abans de fer servir LLM al núvol, material en línia o serveis de vídeo amb IA, afegiu les claus d'API corresponents a la configuració bàsica de la WebUI.

### Desplegament amb Docker 🐳

#### ① Inicieu el contenidor de Docker

Si no teniu Docker instal·lat, primer [baixeu i instal·leu Docker Desktop](https://www.docker.com/products/docker-desktop/).
Si feu servir un sistema Windows, consulteu la documentació de Microsoft:

1. [Instal·lar WSL](https://learn.microsoft.com/en-us/windows/wsl/install)
2. [Fer servir contenidors de Docker amb WSL](https://learn.microsoft.com/en-us/windows/wsl/tutorials/wsl-containers)

```shell
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up
```

> L'opció predeterminada recomanada és `docker-compose.release.yml`, que baixa la imatge precompilada de GitHub Container Registry: `ghcr.io/harry0703/moneyprinterturbo:latest`.
> Si necessiteu compilar la imatge localment, encara podeu executar `docker compose up`.
> Abans del primer inici, copieu `config.example.toml` a `config.toml` perquè es pugui muntar als contenidors.

#### ② Accediu a la WebUI

Obriu el navegador i visiteu http://127.0.0.1:8501

#### ③ Accediu a la documentació de l'API

Obriu el navegador i visiteu http://127.0.0.1:8080/docs o http://127.0.0.1:8080/redoc

> Per defecte, l'API permet l'accés des del navegador amb el mateix origen. Definiu la variable d'entorn `CORS_ALLOWED_ORIGINS` només quan un frontend de navegador independent hagi de cridar l'API directament des d'un altre origen, per exemple `http://localhost:3000,https://frontend.example.com`. CORS no afecta curl, Postman, n8n ni altres clients del costat del servidor.

### Desplegament manual 📦

#### ① Creeu un entorn virtual de Python

Feu servir [uv](https://docs.astral.sh/uv/) per gestionar l'entorn de Python i les dependències. El projecte és compatible amb Python 3.11 o posterior; l'exemple següent fa servir Python 3.11.

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

Si encara no feu servir `uv`, podeu continuar fent servir `venv + pip`.

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Notes:

- `pyproject.toml` és ara el manifest principal de dependències.
- `uv.lock` fixa l'entorn resolt, de manera que es recomana `uv sync --frozen` per defecte.
- `requirements.txt` només es manté per a la instal·lació antiga basada en `pip`.

#### ② Inicieu la WebUI 🌐

Tingueu en compte que heu d'executar les ordres següents al `directori arrel` del projecte MoneyPrinterTurbo

###### Windows

```powershell
.\webui.bat
```

També podeu executar `webui.bat` a CMD.
`webui.bat` prioritza el `.venv` del projecte o el Python inclòs al paquet portàtil. Si no es troba cap Python del projecte però `uv` està instal·lat, recorre automàticament a `uv run streamlit`.
Per permetre que altres dispositius de la vostra xarxa local accedeixin a la WebUI, executeu `set MPT_WEBUI_HOST=0.0.0.0` abans d'executar `webui.bat`.

###### macOS o Linux

```shell
sh webui.sh
```

L'script fa servir automàticament l'entorn virtual del projecte o `uv` i selecciona un port local disponible. Per permetre l'accés des d'altres dispositius de la vostra xarxa local, executeu:

```shell
MPT_WEBUI_HOST=0.0.0.0 sh webui.sh
```

Després d'iniciar-la, el navegador s'obrirà automàticament

#### ③ Inicieu el servei d'API 🚀

```shell
uv run python main.py
```

Si ja heu activat l'entorn virtual manualment, també podeu executar:

```shell
python main.py
```

#### ④ Mode només CLI (sense navegador) ⌨️

Si no podeu fer servir un navegador ni la redirecció de ports, genereu vídeos directament des de la
línia d'ordres. L'ordre de generació completa més senzilla és:

```shell
uv run python cli.py --video-subject "How AI is changing everyday life"
```

Les opcions d'estil dels subtítols i de veu en off es resolen en aquest ordre: **opció de CLI explícita >
valor `[ui]` desat a `config.toml` > valor predeterminat integrat**. Altres paràmetres de generació,
com ara la música de fons, el nombre de vídeos i el nombre de paràgrafs, no s'hereten de
la WebUI. Si la WebUI està configurada per fer servir àudio pujat, passeu `--custom-audio-file`
explícitament, ja que la ruta pujada no es desa.

Per consultar la referència completa d'ordres, les descripcions dels paràmetres i les instruccions d'ús,
executeu:

```shell
uv run python cli.py --help
```

Per executar diverses tasques de manera seqüencial, passeu una matriu JSON o un manifest JSONL en UTF-8. Les
opcions de CLI actuen com a valors predeterminats, i cada objecte en sobreescriu els camps de `VideoParams`:

```json
[
  { "video_subject": "How solar panels work" },
  { "video_subject": "How wind turbines work", "video_aspect": "16:9" }
]
```

```shell
uv run python cli.py --batch-file ./tasks.json --stop-at video
```

El manifest es resol a partir del directori de treball actual. Els valors relatius de
`custom_audio_file` i els valors locals de `video_materials[].url` que conté es resolen
a partir del directori del manifest; les rutes de fitxer proporcionades com a valors predeterminats de la CLI mantenen la semàntica
habitual del directori de treball actual. Un manifest està limitat a 100 tasques i 1 MiB.
Totes les entrades es validen abans que comenci la primera tasca, les tasques continuen després d'una
fallada d'execució individual i l'ordre imprimeix un únic resum JSON en acabar.
El resum conté `total`, `succeeded`, `failed` i `tasks`; cada entrada de tasca té
`index`, `task_id`, `status`, `result`, `failed_stage` i `error`.

## Veu en off, subtítols i música de fons 🎙️

### Síntesi de veu

**Azure TTS V1** a la WebUI funciona amb **Edge TTS** i és d'ús gratuït sense clau d'API. MoneyPrinterTurbo també admet **Azure TTS V2**, **SiliconFlow TTS**, **Google Gemini TTS**, **Xiaomi MiMo TTS**, **MiniMax TTS**, **ElevenLabs TTS**, **Chatterbox TTS** autoallotjat, **Kokoro TTS** autoallotjat, **Fish Audio TTS**, [ModelBest VoxCPM TTS](https://platform.modelbest.cn/console/docs/api/audio) i un mode sense veu.

Seleccioneu un proveïdor i una veu a la WebUI i seguiu les instruccions de la pantalla per a les credencials necessàries. Edge TTS no requereix clau d'API; [Azure TTS V2](https://portal.azure.com/) i altres proveïdors al núvol requereixen credencials de les seves plataformes respectives. Consulteu les veus d'Edge TTS disponibles a la [llista de veus](./docs/voice-list.txt).

ModelBest VoxCPM requereix una clau d'API i un ID de model amb la capacitat `speech_synthesis`. La seva resposta SSE transmet àudio WAV, que MoneyPrinterTurbo converteix automàticament a l'MP3 que fa servir el procés de vídeo. A més de la conversió estàndard de text a veu, la WebUI pot clonar la identitat del locutor a partir d'un àudio de referència opcional. El lliurament d'alta fidelitat reutilitza per defecte aquest clip amb la seva transcripció exacta, o accepta un exemple d'interpretació separat, i envia `prompt_audio` i `prompt_text` per continuar-ne el ritme, l'emoció i la pronunciació. La WebUI pot fer servir la configuració local de Whisper per crear un esborrany de transcripció editable. Les pujades estan limitades a 20 MiB i cada WAV convertit a 5 MiB. El material de referència està limitat a la sessió de navegador i a la tasca actuals, i no s'escriu a la configuració, als preajustos, a l'historial de tasques ni als registres.

### Generació de subtítols

Hi ha dos modes de generació de subtítols disponibles:

- **edge**: fa servir les marques de temps del TTS, s'executa ràpidament sense GPU i és el mode predeterminat.
- **whisper**: fa servir la transcripció local amb `faster-whisper` quan cal una línia de temps de subtítols més precisa. El model es baixa el primer cop que s'utilitza.

Definiu `subtitle_provider` a `config.toml` per canviar de mode. Whisper fa servir per defecte el model `large-v3`, d'aproximadament 3 GB. Per fer servir el model `large-v3-turbo`, més petit i ràpid, d'aproximadament 1,6 GB:

```toml
[app]
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3-turbo"
```

> El primer cop que s'utilitza, Whisper baixa automàticament el model de Hugging Face. Si la baixada automàtica falla, baixeu `whisper-large-v3` manualment des de [Hugging Face](https://huggingface.co/Systran/faster-whisper-large-v3).

Després d'extreure el model, col·loqueu tot el directori a `.\MoneyPrinterTurbo\models`. La ruta final ha de ser `.\MoneyPrinterTurbo\models\whisper-large-v3`:

```
MoneyPrinterTurbo
  ├─models
  │   └─whisper-large-v3
  │          config.json
  │          model.bin
  │          preprocessor_config.json
  │          tokenizer.json
  │          vocabulary.json
```

## Preguntes freqüents 🤔

<details>
<summary>RuntimeError: No ffmpeg exe could be found</summary>

Normalment, ffmpeg es baixa i es detecta automàticament.
Tanmateix, si el vostre entorn té problemes que impedeixen les baixades automàtiques, és possible que us trobeu amb l'error següent:

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```

En aquest cas, baixeu FFmpeg des de [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), extraieu-lo i definiu `ffmpeg_path` amb
la ruta d'instal·lació real.

```toml
[app]
# Definiu-ho segons la vostra ruta real; tingueu en compte que a Windows els separadors de ruta són \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

</details>

<details>
<summary>OSError: [Errno 24] Too many open files</summary>

Aquest problema el causa el límit del sistema en el nombre de fitxers oberts. El podeu resoldre modificant el límit de fitxers oberts del sistema.

Comproveu el límit actual:

```shell
ulimit -n
```

Si és massa baix, el podeu augmentar, per exemple:

```shell
ulimit -n 10240
```

</details>
